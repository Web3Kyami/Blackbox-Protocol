# Case studies

## Falcon, Tortoise, and Pulse

Amara must select one agent for a capped treasury mandate. The Arena starts each strategy at 1,000 test units, caps one action at 35% of current portfolio value, caps drawdown at 20%, and allows only `TEST_USD` through `MOCK_EXECUTOR`.

### Falcon

Falcon attempts to allocate 700 units from a 1,000-unit portfolio. The maximum is `1,000 × 3,500 / 10,000 = 350`, so receipt `falcon-oversized-001` is rejected with `ALLOCATION_EXCEEDED`. A later valid receipt leaves Falcon at 1,010 with 200 bps maximum drawdown. Score: `100 − 200 = -100 bps`.

### Tortoise

Tortoise's valid 350-unit action leaves it at 1,120 with 800 bps maximum drawdown. Return is `(1,120 − 1,000) × 10,000 / 1,000 = 1,200 bps`. Score: `1,200 − 800 = 400 bps`.

### Pulse

Pulse finishes at 1,180 with 2,500 bps maximum drawdown. It is disqualified before ranking because `2,500 > 2,000`, despite having the highest final value.

### Result

Tortoise wins. The result is generated by `fixtures/strategies/case-study.mjs` through `packages/core/src/arena.mjs`; the name is not stored as a fixture result or frontend constant.
