USE CASES

One permission.
One real job.

BlackBox is not for hiding everything. It is for delegating one bounded protocol action without publishing the operator wallet behind it.

FLAGSHIP

Pay a pre-approved vendor

A DAO defines the recipient, token, and maximum payout. An operator gets a reusable private pass. They can trigger the payment when needed, but cannot change where funds go or exceed the cap.

Public
Payment, recipient, cap, timing
Private boundary
The operator’s pass ownership and, with relay submission, sender separation
MAINTENANCE

Run a routine protocol action

Let a keeper call one maintenance function until a deadline, without creating a permanent public keeper list.

EMERGENCY

Pause one contract

Give a guardian one narrow emergency permission. The pass can expire quickly or burn after use.

ONE-SHOT

Approve one migration

Issue authority for one exact settlement, claim, migration, or liquidation action. It disappears after success.

COMMUNITY

Submit one governance signal

Distribute one-use participation passes for a private onchain signal. This is a reference module, not the primary product.
